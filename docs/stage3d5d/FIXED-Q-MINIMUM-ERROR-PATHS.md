# Stage 3-D-5D：固定Q非交差保証に必要な誤差経路の限定

## 結論と区別
**固定Guideの保存BRepが表す数学的幾何集合**に限れば、既存の閉Shell・全10トリム済みPlane Face・48保存pcurve・向き付き領域・Location・D2全点境界対応を利用できる。距離最適化器や数値版FaceClassifier/SolidClassifierの全点正しさは証明の前提ではない。

これと「OCCTの数値APIが任意の入力で正しいIN/OUTを返す」「物理部材が設計形状に忠実である」「Boltが全運動区間で接触しない」は別命題である。前者を解決するために後者を全件必須にしない。

## 経路の分類

| 経路 | 固定Qの保存BRep幾何集合の非交差 | 有限誤差を含む実材料への昇格 | 今回の根拠 |
| --- | --- | --- | --- |
| Solid→Shell→全10Faceの閉じた境界網羅、向き、外側の定義 | **必須／既存PASS** | **必須／有限意味論の追加保証はUNKNOWN** | `solid-boundary-census`, `semantic-bridge` |
| 保存48 pcurve・Edge 3D直線・全パラメータ域アフィン同値 | **必須／既存PASS** | 点評価の実誤差が必要になる場合のみ追加 | `stored-pcurve`, `trim-correspondence` |
| Face/Wireの外輪と内輪、実効Location、10 Geom_Planeと向き | **必須／既存PASS** | 実境界の包絡が必要なら追加 | `semantic-bridge`, `plane-roundoff` |
| Qおよび中心から無限遠への半直線の境界非交差 | **必須／今回厳密検算** | **必須／真の境界がこれらを避ける保証はUNKNOWN** | `narrow-error-paths.json` |
| Face/Edge/Vertexの公差数値 | 観測として有用・必要な誤差上界にはならない | 差分解釈の根拠にはなるが、そのまま上界にしない | `native-tolerance-audit` |
| Geom_Plane::D0の丸め（限定） | 必須ではない（数学的保存係数を使うため） | その直接評価の出力を使う場合のみ | `plane-roundoff-bound` |
| `BRepExtrema`探索/収束/最短距離 | **不要** | 距離APIの戻り値を証拠に使う場合のみ | 最小距離は有理数矩形分離で算出 |
| すべてのpcurve交差器、FaceClassifier、SolidClassifierの全点誤差 | **不要** | そのAPI出力による内外判定を使用する場合だけ個別評価 | 本証明はAPIのIN/OUTを使用しない |
| Boolean差分・Volumeなどの全点数値正しさ | **不要** | それを材料包含の証明に採用する場合のみ | 本工程では採用しない |
| 代表運動・128区間・全モデル | **対象外** | 後続別工程 | 固定Guide/固定Qに限定 |

## 固定Qと外部経路を別々に証明
単位mm、Q=`[-201,-179]×[-115,-95]×[1000,1040]`、中心`c=(-190,-105,1020)`、半直線 `L={ (x,-105,1020) | x≤-190 }` とする。

旧証明済みの厳密トリム済みFace（Face0/9の穴を除く）16枚の**閉矩形片**について、各片の軸区間とQの分離を分数演算で計算する。同様に、無限に伸びる半直線と閉矩形片の距離を解析的に求める。半直線のx方向の間隙は `max(xmin_rect − (−190), 0)`、y,z方向は点と区間の間隙。したがって半直線を無限回サンプリングする必要はない。

- `dist(Q, ∂M)² = 1 mm²`、ゆえにQからの距離は **1 mm**。
- `dist(L, ∂M)² = 121 mm²`、ゆえに中心半直線からの距離は **11 mm**。
- 各FaceのQおよびLに対する厳密分離値は新規receiptへ個別記録する。全16片から最小値を算出するため、特定のFaceだけを黙って除外しない。

Qは凸・連結で、LはQ中心から負のx方向の無限遠へ接続する。境界とQ・Lが非交差し、実Solidが**有界な正則閉材料集合**であると保証されれば、中心から無限遠への経路が材料側に入れないため、Q全体は材料外にある。この含意は数値`SolidClassifier`に依存しない。

## 誤差上界が必要となる場合も、対象をさらに限定
理想境界を`B=⋃F_i`、有限実誤差を含む材料境界を`B_actual`とする。仮に**実境界の全点が漏れなく**各対象Face `F_i` の`δ_i`近傍に入ること（余分な境界成分なし）を証明でき、しかも各`δ_i< min(dist(F_i,Q),dist(F_i,L))`なら、`B_actual∩(Q∪L)=∅`となる。これは**一方向の境界包絡**で足り、双方向Hausdorff一致や任意の分類器全点正しさを追加で要求しない。Face対応自体を保証できない場合は、全境界を理想境界の `δ<1mm` 近傍に含む**一方向の均一上界**が十分条件となる。

今回のnative公差最大値 `7.2529275995e-5mm`、Plane直接D0評価の限定上界約`3.744e-12mm`、保存係数の有理数等式は、いずれも上記の**全材料境界包絡δ**そのものを保証しない。したがって、厳密保存BRep意味論の条件付き幾何PASSを維持する一方、実行時の全浮動小数演算を含む`B_actual`の一方向包絡は**UNKNOWN**のままとする。

## 検証方法と停止線
`fixed_q_minimum_error_paths.py` は前の検証済み原票（保存48 use、トリム領域、向き付きSolid境界一致、公差監査、Plane直接評価）を同じ固定FCStd/D2/BRep SHAに結合する。旧 `face_rects` で全10Face→16閉片を再構成し、Q・Lとの厳密距離、10枚それぞれの閾値、必須・不要誤差経路を単一receiptに書く。追加数値サンプリング・新しい材料モデル・Bolt運動・別PRは不要。

このreceiptがPASSしても、`native_q_all_point_geometric_nonintersection_with_finite_error=UNKNOWN`、`native_representative_interval=NOT_TESTED`、総合PARTIAL、PR Draft・マージHOLDを維持する。無関係なAPIの誤差監査を続けることを受入条件にしない。
