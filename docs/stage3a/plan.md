## 設計と受入境界

左右支持柱、上部横材、板戸、模式軸、左右接続部の7部材を独立IDで扱う。門扉の姿勢B0/B1/B2は0/45/90度であり、木柵の改訂B0/B1/B2とは異なる。正本はFreeCAD、メートルで管理する仕様からCAD内部mmへ明示変換する。CADからSTEPとメッシュを取得し、Blenderで材質を付けGLBへ出力する。

静的な3姿勢、部材ID・寸法・座標・接続面・干渉の検証に限る。連続開閉の安全性、軸受の製作法、地耐力、木材強度、耐候性や人体安全は受入対象外。特定城での採用・配置も対象外。

Native TechDrawの正面・平面・側面・軸詳細・接続図と、Web選択用CAD投影図を区別する。寸法変更の実行前後と保存再読込を記録し、固定文字列の整合だけでは合格にしない。
