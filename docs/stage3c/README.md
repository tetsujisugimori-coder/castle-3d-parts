## 根拠と試作

`research-boundary.json` はSRC→OBS→HYP→DEC→VERをStage3C名前空間で結ぶ。旧台帳のheld/reference_onlyや現況情報を変更しない。

[JAANUSの閂](https://www.aisf.or.jp/~jaanus/deta/k/kannuki.htm)の一般語義と保持部材の説明を確認した。掲載の類例を戦国末期山中城の実測・標準仕様へ転用しない。[木戸門](https://www.aisf.or.jp/~jaanus/deta/k/kidomon.htm)の構成説明も一般比較に留める。資料画像は転載していない。

[三島市の環境整備説明](https://www.city.mishima.shizuoka.jp/page/1301.html)は西木戸口等の整備範囲と修景表示を述べるが、今回必要な閂・支持・仕口寸法の根拠を取得したわけではない。考古学的な木戸閉鎖機構は未確認。CAD値はすべて試作D。

## 動作契約

CADを形状・寸法・軸の正本とし、そこから抽出した共通仕様でWebの入力を制限する。閉鎖姿勢以外で閂移動を拒否し、閂が完全に引き抜かれていない場合は開放を拒否する。途中位置も施錠/解錠の二値へ丸めず表示する。不正入力は状態を変えない。

幾何学的接触、状態機械による拒否、実物の荷重伝達は異なる。ソフトウェアが開放を拒否しても、実物が施錠力に耐える証明ではない。支持接触があっても摩擦、変形、木材強度、締結、摩耗はUNKNOWN。

## 検証範囲

BRep common体積とdistToShapeによる標本検査を使用する。BBox重なりを貫通の最終判定にしない。連続角度・直動の標本間は、別の証明がない限りUNKNOWN。検査した標準形状以外のパラメータへ保証を一般化しない。

FreeCAD Qt offscreenおよびBlender backgroundの実起動・保存再読込と、人によるGUI操作は区別する。実機Safari、物理タッチ、手動GUIは記録がない限りNOT_TESTED。

候補Webビルドのみ。本番Pages、マージ、Draft解除は行わない。

## 追加部品と互換性

既存15部材を別候補に引き継ぎ、閂1、案内受け2、柱側閂受け1、戸当たり1、柱横木の試作接合材2、軸方向の抜け止め候補1を追加する。合計23部材。新接合材は外付け試作材であり、実物のほぞ・仕口を復元したと扱わない。

扉角度0〜90°、基準姿勢0/45/90°を維持する。閂は長さ900mm・断面20×40mm、移動0〜140mmを基準にする。CADではmm、共通データとWebではmを用いる。閉鎖許容角度は0°で、閂が途中位置にある場合も扉開放を拒否する。これらの寸法・許容値は史料値ではない。

## CADの状態操作と持ち運び

`cad/stage3c/state.py` の状態遷移APIと保存状態検証器が不正状態を拒否する。FreeCADの標準プロパティ編集画面そのものに入力禁止を追加したわけではない。直接編集した不正状態は、再読込後の検証で拒否する。任意のCAD GUI操作に対するインターロックを保証しない。

この実行環境では通常のopenDocumentから図面を再保存すると一時ディレクトリ不足のエラーが発生した。検証済みのバッチ読込経路は、新規Documentに書込み可能なTransientDirを指定し、コピーしたFCStdをrestoreする方法。FCStdには6図面のテンプレートSVGを内包し、外部テンプレートのパス書換えをせず保存・再読込を検査する。通常経路の失敗記録は独立証拠へ残す。手動GUIの検証成功を意味しない。

## 設計修正と保証の境界

初期案では閂案内の左受けが、140mm挿入時に閂から離れた。受け位置を修正し、全移動範囲での案内関係を確認する。初期失敗を消さず、最終形状の全標本を再検査する。Blenderのアニメーション書出しも、分離したアクションで閂トラックが欠落する反例を保持し、統合アクションで再出力・再読込する。

接触11箇所は理想剛体の接触・隙間の説明に限る。軸の抜け止め、閂受け、接合材が現物で十分な荷重を伝達することは未検証。連続経路、強度、摩擦、変形、施工方法、史実上の採用は別途検証を要する。

移動量140mmはCADの保存プロパティと共通仕様に保持するが、この版の検証契約は140mmに固定している。長さ・幅・高さ・案内隙間の変更は寸法連動試験を行う一方、任意の移動量・軸・制限値へ変更した場合は共通仕様の再生成と再検証が必要。未検証のパラメータ変更を安全な機構として自動承認しない。

## ローカル受入結果（正式CI前）

主担当の最終標本は、扉91角度×297対＝27,027対、閂141位置×37対＝5,217対、固定406対。交差体積0.0001mm³を超える貫通は0。零距離の接触は別区分であり、正の体積を接触として許容していない。

Node 487試験、従来Stage3Bのportable15試験、新Stage3C portable故障対照11試験が成功。Chromium/WebKit×4幅×2motionの16条件と34故障対照が成功。共有化したStage3Bは16条件と26故障対照が成功。既存試験の一時ファイルコピーで/tmp容量不足が出たため、原失敗ログを残してworkspaceの専用TMPDIRへ変更し、同じ全試験を再実行した。

独立担当が14姿勢3,542対、Blender/GLB16組、状態158条件、寸法3組、コピーFCStd再保存、両ブラウザの新規操作を確認した。欠落した衝突ペア・中間標本・生成元hash・重複接触ペアの誤受理は、修正前受理／修正後拒否を実行して照合している。
