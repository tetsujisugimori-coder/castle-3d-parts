# Shape correspondence: observations versus guarantees

The real original is a parametric Part::Box bolt and a Part::Cut left guide. The cut refers to a stock Part::Feature BRep and a parametric Part::Box bore. Native CAD uses mm; the state API accepts metres and multiplies by1000. The extractor records expressions, dependency names, placements, BRep bytes, surface/edge types, face wire counts, vertices, solids, validity and OCC min/max tolerances. These are reproducible **observations**, not exact geometric propositions. Observed tolerances are not a certified Hausdorff error. The parametric history alone does not certify that serialized imported shape faithfully realizes every ideal operation.

The D2 ideal bolt is [-400,500]×[-115,-95]×[1000,1040]mm at travel0. Guide stock is [-200,-180]×[-130,0]×[990,1050]; nominal through-bore has y[-116,-94],z[999,1041]. Four ideal boxes outside this bore define the D2 solid. Under the ideal model, the bolt translates +X0..140mm, guide remains fixed and minimum gap is1mm. D2 exact arithmetic independently gives128PASS; none of this establishes imported BRep equivalence.

Candidate whole-stock enclosure sacrifices the hole. It intersects the nominal bolt at every travel value, so even an exact stock enclosure cannot prove separation. Candidate four-wall enclosure requires both outward occupancy bounds and an inward-certified void: if the bore is actually smaller than assumed, extra guide material may intersect the bolt. A Boolean cut with zero observed residual volume cannot rule out lower-dimensional remnants or kernel error; finite vertex/mesh samples cannot bound all surfaces. No certified arithmetic relation between stored BRep, trimmed faces, Boolean classification and simple solid is implemented. Thus candidate containment is UNKNOWN, not PASS or a geometric FAIL. Distance-error and motion-bound guarantees for actual CAD remain UNKNOWN separately. Neither source identity PASS nor observation equality unlocks D2 CAD application.

`evaluate` compares observation to a reference freshly read from pinned source in the native process. It detects alterations of native BRep/placement metadata and unit/source/range mismatch. It is an **observation consistency gate**, not an independently authenticated arbitrary JSON certificate. Matching inputs still yield UNKNOWN. Caller proof/PASS claims are ignored. A forged internally consistent report cannot produce CAD PASS; its authenticity still requires raw source and execution audit. Pinned D2 contract hash prevents silent redefinition of expected source hashes.

Five native counterexamples use independent memory shape copies, never saving the original: wider bolt, reduced hole (added wall), placement shift, nominal-contact shift and5e-8mm near-tolerance shift. BRep/placement change is the rejection reason, not an assertion that a near-tolerance physical collision was proven. Metadata controls are portable synthetic tests, not actual CAD or browser faults. No old-version RED is claimed for new cases. Raw original23 IDs and source hashes before/after are retained.

Alternatively explicitly approve a new analytic CAD authoring contract in another task. Neither is silently implemented here. No need to develop a general CAD prover or redesign originals in this PR.
