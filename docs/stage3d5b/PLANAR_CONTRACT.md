# Planar continuation: contract fixed before implementation

Applies only to Issue38 / DraftPR39 after reviewed563195c. Overall PARTIAL / merge HOLD. Definitions are proposed acceptance rules, not approval or proof of their satisfaction.

## Scope and sets
Units m for exact arithmetic, mm for unmodified FreeCAD observations. World coordinates use recorded serialized Location; XML Placement is not reapplied. Supported mathematical class: finite bounded regular-closed rectilinear polyhedra with connected manifold boundary and planar faces trimmed by simple axis-aligned Line polygons. Boundary is included in material A; void is its open complement. One outer wire per face, any disjoint inner wires with opposite winding; all faces/edges/vertices must be covered. Unsupported surfaces/curves, degeneracy, missing trims or ambiguous topology are rejected as invalid mathematical input or UNKNOWN for unsupported real input. All-plane observations alone do not certify this class.

The exact verifier constructs the atomic coordinate arrangement from every trim vertex, determines material by oriented crossing, and verifies every atomic boundary patch against every supplied oriented face. This is a theorem about the supplied rational boundary, not a selfdeclared cell list. A comparison to model M must establish A subset M; certified void V must satisfy V subset complement(A). Filled-hole outer envelopes cannot certify passage. Closed query cells contacting material are rejected by the empty-space specification. Nonpositive clearance bounds mean safety unproved; they do not establish penetration.

## Staged gates
Research/tool acceptance: deterministic rational boundary coverage, normal/fault controls, explicit unsupported/missing evidence outcomes, unchanged prior assets/contracts, final-HEAD official regressions, independent derivation/implementation review and original artifact/source/readback audit. Defining these gates does not discharge them, nor authorize merge.

Real safety acceptance additionally requires complete native BRep-to-trim/surface parameter enclosures with topology and oriented material semantics, certified local/parent/Document/world transform equivalence, finite shape/extraction/transform/rounding/pose errors and continuous-motion bound for the exact reference pose/interval. NO metadata flag or caller assertion can enable real PASS. Missing any premise -> UNKNOWN, unexecuted interval oracle -> NOT_TESTED. Known malformed input -> input-contract FAIL (not a physical collision claim).

## Numeric and placement contract
Exact IEEE float values may be converted by as_integer_ratio; this encloses the stored observation, NOT an unknown CAD real. No snapping near-axis matrices, decimal conversion, arbitrary epsilon or tolerance-as-model-error. Interval arithmetic evaluates affine compositions over bounded domains with directed exact rational endpoints. Geometry/extraction, transform input enclosures, arithmetic/rounding, pose and motion are separate components; unknown components are null. Finite conditional results explicitly state their supplied enclosure premises. Matrix coefficients need not be exact rotations; any rigid-rotation-specific bound requires proof of orthogonality/axis/radius/angle.

Original FCStd is never opened for recompute/repair/save. Native read-only member import and untouched Shape byte hashes are separate from a byte-identical isolated FCStd copy opened as a Document. The copy may recompute at0/70/140mm only in a private output directory, never save. Record XML Placement, imported Shape Location, object Placement, getGlobalPlacement, parent links, expressions and before/after observations. Sample equivalence remains observational; no all-state/continuous promotion. Static differences/missing/duplicate transforms must not silently normalize away.
