# 第3層から将来のCAD採用履歴への参照契約

第4層は今回実装しない。正式CAD/FreeCAD/STEP/GLBは生成せず、木柵v0の仮寸法・原本を変更しない。

## 将来必要な採用記録

- 部品ID・版、参照repository・固定commit/tree、HYP ID・revision・canonical SHA256。
- 採用理由、採用/不採用の競合案、採用者・日付、未確定事項、適用範囲。
- パラメータごとの値・単位・測定対象、原値・原単位・換算式、SRC/箇所/OBS/測定ID、対象城郭への適用根拠。
- CAD・STEP・GLBの各hashと実測結果、原本再読込確認。仮説状態とモデル検証状態を別管理。

参照は SRC → OBS → CMP/HYP → 将来の採用記録 の方向。上位の仮説をSRC/OBSへ逆流させない。仮説が更新されても既存採用版を自動更新しない。

## 根拠区分

| 値の区分 | basis | 対象城郭への適用 |
| --- | --- | --- |
| 原資料の報告値 | source_reported | 対象城の当該測定対象が一致し、出典と値の結び付きを確認する |
| 報告者推定 | reporter_estimate | 推定者・元の留保・算定根拠を保持する |
| 他城類例推定 | other_site_analogy | 比較CMP・地域/年代/機能差と適用限界を記録。対象城の実測値にしない |
| 復元者仮説 | restorer_hypothesis | 根拠と未確定範囲を記録し、推定Cとして表示 |
| 展示用仮設定 | display_provisional | 演出D/暫定設定として表示し、史実の寸法にしない |

現行HYPでは柱高、柱径、柱間隔、柱本数、横木段数、断面形状、配置方法をすべてnullとする。m/count/descriptionを区別する。正の数値・整数数量・単位は検査するが、技術的に妥当な数値が歴史的に妥当とは限らない。

現行OBSの数値は柱穴数、定義未確認の柱穴間隔、残存深さ。これらはCAD柱本数・芯々間隔・当初根入れ/柱高へ自動転用できない。現行validatorは出典を持つ数値→CADへの非null適用をfail closedにする。将来の意味対応契約が独立審査されるまで有効化しない。復元者・展示仮設定は明記した改訂で許容できるが、今回初期データでは設定しない。

全仮説のcad.eligibilityはreference_only。これは自動採用許可ではない。正式部品として検証済みという状態も第3層に設けない。
